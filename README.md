# ONG Transformar

Projeto web desenvolvido para a ONG Transformar com o objetivo de apresentar a instituição, seus projetos sociais e disponibilizar uma área de cadastro para participação nas ações da ONG.

## Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- HTML5 para estruturação das páginas;
- CSS3 para estilização, responsividade, Flexbox e CSS Grid;
- JavaScript para interatividade e manipulação do DOM;
- ES Modules para modularização do código JavaScript;
- LocalStorage para persistência de dados no navegador;
- SweetAlert2 para exibição de alertas personalizados;
- Git e GitHub para versionamento e gerenciamento do repositório.

## Funcionalidades

- Navegação no formato SPA (Single Page Application);
- Menu responsivo;
- Apresentação dos projetos da ONG;
- Formulário de cadastro com validação;
- Persistência de dados utilizando LocalStorage;
- Alertas personalizados com SweetAlert2;
- Recursos de acessibilidade para navegação por teclado;
- Layout responsivo utilizando CSS Grid e Flexbox.

## Estrutura do projeto

- `html/` - páginas e estrutura HTML da aplicação;
- `css/` - arquivos de estilização;
- `js/` - scripts, módulos e funcionalidades da aplicação;
- `images/` - imagens utilizadas no projeto.

## Instalação e execução local

1. Clone o repositório:

   `git clone https://github.com/Balucar/projeto-ong.git`

2. Acesse a pasta do projeto:

   `cd projeto-ong`

3. Abra o projeto no Visual Studio Code.

4. Abra o arquivo `html/index.html` em um navegador ou utilize uma extensão de servidor local, como o Live Server.

O projeto utiliza tecnologias web nativas e não possui dependências que necessitem de instalação por gerenciadores de pacotes.

## Build e testes

Por utilizar HTML, CSS e JavaScript nativos, o projeto não necessita de um processo específico de build.

Os testes são realizados diretamente no navegador, verificando navegação, responsividade, validação do formulário, persistência de dados e recursos de acessibilidade.

## Versionamento

O projeto utiliza Git e GitHub para controle de versão.

Foi adotado um fluxo baseado em GitFlow, utilizando:

- `main` para versões estáveis;
- `develop` para integração das funcionalidades;
- `feature/acessibilidade` para desenvolvimento da melhoria de acessibilidade.

As alterações são registradas por meio de commits e Pull Requests. Issues e Milestones são utilizados para organizar e acompanhar as melhorias do projeto.

O projeto utiliza versionamento semântico no formato `MAJOR.MINOR.PATCH`. A primeira versão estável foi identificada como `v1.0.0`.
